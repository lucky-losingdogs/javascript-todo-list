## Features

* Interaction between HTML, CSS and JavaScript to create a functional to-do list web application with a formatted layout.
* An input bar for users to add tasks.
* Interactability to allow for striking out tasks or deleting them.
* A search bar that displays tasks matching the search text.
* Tasks are saved and loaded when the page is refreshed.

## Future Improvements

* A filter system to display certain tasks, for example display only uncompleted tasks.
* Navigation through the tasks via arrow-key.
* Being able to update task text after adding it.
